Self-improvement log — mistakes made and rules to prevent recurrence.
Review this file at the start of every session.

## Format

```
### YYYY-MM-DD — <Short Title>
**Mistake:** What went wrong
**Root Cause:** Why it happened
**Rule:** Concrete rule to prevent recurrence
```

---

## Rules in Effect

| # | Rule |
|---|------|
| 1 | Enter plan mode for any task with 3+ steps or architectural decisions |
| 2 | Never mark a task complete without running tests or demonstrating correctness |
| 3 | If something goes sideways mid-task, STOP and re-plan — don't keep pushing |
| 4 | Always read a file before proposing changes to it |
| 5 | Only touch code that is necessary — minimal impact, avoid collateral changes |
| 6 | Prefer editing existing files over creating new ones to reduce file bloat |
| 7 | No temporary fixes — find root causes and fix them properly |
| 8 | After any correction from founder, update this file immediately |
