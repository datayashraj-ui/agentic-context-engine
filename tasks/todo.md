## How to Use This File

1. **Plan First** — write all tasks here before starting implementation
2. **Verify Plan** — check in with founder before building
3. **Track Progress** — mark items `[x]` as completed
4. **Explain Changes** — add high-level notes after each step
5. **Document Results** — add a review section at the bottom when done
6. **Capture Lessons** — update `lessons.md` after any correction
